# 恒昌橡塑订单管家

> 一句话：把客户发的订单照片丢进来，自动帮你记到腾讯文档表格里，以后查发货、对账都不用翻微信聊天记录了。

---

## 谁可以用

做中间商、代工厂、贸易生意的。比如客户让你下单，代工厂发完货给你送货单——以前你要手抄到 Excel，现在拍照就行。

## 怎么用（3 步）

### 1. 装好工具

先装 WorkBuddy，然后把腾讯文档连上。不会装？找年轻人帮你。

### 2. 录订单——客户发了采购单，拍照发我

```
对着订单拍照 → 发到对话框 → 说"录入"
```

我会告诉你识别到了什么：哪个客户、什么订单号、几个产品。你说"对"，我就写进表格。新写的行是黄底的，你回头看一眼，没问题就把黄色去掉。

### 3. 录发货——代工厂送货了，拍照发我

```
对着送货单拍照 → 发到对话框 → 说"发货，录入"
```

我写到发货总表里。订单总表里"已发多少""还剩多少"自动算——不用你管。

### 4. 对账——月底要给客户发账单

```
说"生成5月对账单"
```

我把这个月发过的货列出来，产品、数量、单价、总价都有。你核对一下就能发给客户收钱了。

---

## 表格长什么样

就三张表：

| 表名 | 干嘛的 |
|------|--------|
| 客户订单总表 | 客户发来的每个订单，一行一个产品 |
| 发货总单 | 代工厂每次送来的货，一行一个产品 |
| 对账单 | 月底从这里抄出来发给客户 |

## 遇到问题

- 照片拍得清楚吗？手机正对着单子拍，不要斜着
- 说的"录入"对吗？录订单说"录入"，录发货说"发货"
